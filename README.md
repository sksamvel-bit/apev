# ⚡ Tesla Model 3 & Model Y In-Car Navigation (Georgia EV Edition) — v3.9.4

> **სპეციალურად Tesla Model 3-ისა და Model Y-ის 15-ინჩიან ცენტრალურ ეკრანზე (MCU2 Intel Atom და MCU3 AMD Ryzen) მორგებული სრულფასოვანი ნავიგაციის სისტემა.**
> **v3.9.4 სიახლე:** სრულფასოვანი **360° Multi-Touch რუკის როტაცია (Tesla Native UX)**: 2 თითის გადაგრეხის ჟესტით (Twist-to-Rotate) რუკა თავისუფლად ტრიალებს 360 გრადუსით ნებისმიერი მიმართულებით, ისევე როგორც ტესლას მშობლიურ ნავიგაციაში; კომპასის ღილაკზე 1 დაჭერით რუკა მყისიერად სწორდება ჩრდილოეთზე (North-Up), ხოლო მეორე დაჭერით უბრუნდება ავტომობილის კურსს (Heading-Up).

## 🎯 პროექტის მისია და რეალობა საქართველოში
საქართველოში Tesla-ს ქარხნული ნავიგაცია სრულად შეზღუდულია: არ არის ქართული ენა, ადგილობრივი მარშრუტები, საცობების გათვალისწინება და სიჩქარის ლიმიტები. 
ეს პროექტი შექმნილია როგორც საავტომობილო დონის PWA აპლიკაცია, რომელიც Tesla-ს ჩაშენებულ Chromium ბრაუზერში იძლევა **სუფთა 60 FPS** მუშაობას, მინიმალურ რესურსებს და ავტომობილის მართვაზე მორგებულ ინტერფეისს.

## 🗺️ რუკის მრავალსტილიანი ძრავა (Multi-Style Engine)
ეკრანზე ხელმისაწვდომია 3 ოპტიმიზებული რუკის რეჟიმი:
1. 🗺️ **Google Maps (Roads)** — ოფიციალური Google-ის საგზაო ტაილები ქართულ ენაზე. Rate-limit-ის შემთხვევაში ავტომატური fallback CartoDB Voyager / Dark Matter-ზე.
2. 🟡 **Yandex Maps v2.1** — იანდექსის ოფიციალური ვექტორული რუკა ცოცხალი საცობებით (Live Traffic) და ქალაქის საცობების 10-ბალიანი ინდექსით.
3. 🛰️ **Google Satellite Hybrid** — სატელიტური გადაღება ქუჩებისა და მაგისტრალების ფენით.

## 🧭 ნავიგაცია და მარშრუტიზაცია (`routing.js`)
* **Dual OSRM არქიტექტურა:** მარშრუტის გამოთვლა ორმაგი საჯარო სერვერით. ქსელის დროებითი ჩავარდნისას ძველი მარშრუტი და HUD ინსტრუქციები არ ქრება.
* **Turn-by-Turn HUD:** მოსახვევის მანევრის მკაფიო ისრები, მანძილი, დარჩენილი დრო და ETA.
* **ქართული ხმოვანი ნავიგაცია (`speech.js`):** Web Speech API-ზე დაფუძნებული წინასწარი ხმოვანი გაფრთხილებები (500მ, 150მ და მოსახვევის მომენტში).
* **გრუნტის გზების არიდება:** ოფცია `exclude=unpaved` საქართველოს რთული რელიეფისთვის.

## ⚡ სიჩქარის ლიმიტების ჭკვიანი სისტემა (`speed-limit.js`)
* **Tier-0 OpenStreetMap Overpass ძრავა:** კითხულობს კონკრეტული გზის რეალურ `maxspeed` ტეგს.
* **სივრცითი ბადე და ქეშირება:** ~0.5 კმ-იანი უჯრები, 24-საათიანი ქეში (მაქს. 40 უჯრა), ორი Overpass სერვერის fallback, კურსის მიმართულებით გზის ამოცნობა (22 მ ტოლერანტობა) და წინ მდებარე უჯრის წინასწარი ჩატვირთვა.
* **სანდოობის 3 დონე UI-ში:**
  - `Confirmed` (OSM რეალური ციფრი) ➔ მაგ. `60` წითელი ჩარჩოთი და გადაჭარბების ხმოვანი/ვიზუალური სიგნალით.
  - `Estimate` (მაგისტრალის/ქალაქის მიახლოებითი კორიდორი) ➔ მაგ. `~60` წყვეტილი ჩარჩოთი, ხმოვანი განგაშის გარეშე.
  - `Unknown` (უცნობი მონაკვეთი) ➔ `—`.

## 🔒 უსაფრთხოება და Multi-PIN Single-Device საკეტი
* **მფლობელის Master PIN:** პირველი PIN სიაში განკუთვნილია მფლობელისთვის (ულიმიტო მოწყობილობები).
* **სტუმრის Guest PIN (1 PIN = 1 მოწყობილობა):** მომდევნო PIN-ები პირველივე გააქტიურებისას უკავშირდება კონკრეტულ მოწყობილობას (`pin-bindings.json`). PIN-ის სხვა პირზე გადაცემისას სისტემა ბლოკავს წვდომას.
* **დინამიური AUTH_SECRET:** სერვერის გაშვებისას იქმნება 32-ბაიტიანი კრიპტოგრაფიული გასაღები (თუ env ცვლადი არ არის მითითებული).
* **Server-side Geocoding Proxy (`/api/search`):** კლიენტის პირდაპირი Nominatim მოთხოვნები ჩანაცვლებულია სერვერის პროქსით, 1000 მწმ დაყოვნების მექანიზმით (ToS compliance) და 24-საათიანი ქეშით.
* **Brute-Force დაცვა:** 5 არასწორი მცდელობის შემდეგ IP იბლოკება 5 წუთით.

## ⚡ Tesla MCU-ს ოპტიმიზაციები (60 FPS)
* **სრულიად ამოღებულია** GPU-ს მტვირთავი `backdrop-filter: blur()`.
* **Hardware Canvas Acceleration:** Leaflet-ის რენდერი გადაყვანილია HTML5 Canvas-ზე.
* **R-Gear Recovery (უკანა სვლა):** უკანა გადაცემაში ჩაგდებისას Tesla-ს ბრაუზერი იტვირთება ხელახლა. აპლიკაცია ინახავს მარშრუტის მდგომარეობას `localStorage`-ში, ხოლო Service Worker (`sw.js`) უზრუნველყოფს მყისიერ (0ms) ჩატვირთვას.

### ცვლადები (`.env` ან Render Environment):
* `PORT` — პორტი (ნაგულისხმევი 3000)
* `ACCESS_PIN` — PIN კოდები მძიმით გამოყოფილი (მაგ. `7788,1234,5678`)
* `AUTH_SECRET` — საიდუმლო გასაღები ჰეშირებისთვის (სურვილისამებრ)
* `ADMIN_TOKEN` — დამტენების ხელით სინქრონიზაციის გასაღები (`/api/chargers/sync`)

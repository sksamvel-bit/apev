# ⚡ Tesla Model 3 Navigation - EV Pro (with Yandex Maps & Traffic)

სპეციალურად **Tesla Model 3**-ის 15-ინჩიან ეკრანზე მორგებული სრულფასოვანი ნავიგაციის ვებ-აპლიკაცია:
* 🗺️ **რუკის სტილები (Multi-Style Engine)**:
  - 🖤 **Tesla Cyber Dark** – ღრმა მუქი თემა ნეონის მარშრუტით (Default).
  - 🟡 **Yandex Maps (Live საცობები)** – ოფიციალური Yandex Maps ლაივ საცობების ფენით.
  - 🛰️ **Satellite Hybrid** – რეალური სატელიტური გადაღება ქუჩების ფენით (Tesla Satellite View).
  - 🗺️ **Esri Dark Canvas** – ოფიციალური საავტომობილო Dark GIS რუკა.
  - ☀️ **Day Mode (Light)** – სუფთა, ნათელი რეჟიმი მზიანი დღისთვის.
* 🚦 **საცობების 10-ბალიანი ინდექსი (Yandex Traffic Score)**:
  - ზედა პანელზე გამოტანილია ქალაქის რეალური საცობის ბალი (1-დან 10-მდე: 🟢 1-3 თავისუფალი, 🟡 4-6 შეფერხებული, 🔴 7-10 მძიმე საცობი).
* 🚧 **საგზაო ინციდენტები და კამერები (Road Alerts)**:
  - 💥 ავარიები (Crash)
  - 🚧 საგზაო სამუშაოები
  - 📹 სიჩქარის რადარები და Bus Lane-ის კამერები
* 🛣️ **ზოლების ასისტენტი (Lane Guidance)**:
  - Turn-by-Turn HUD-ზე მოსახვევის წინ აჩვენებს რეკომენდებულ ზოლს (მაგ. `| ↰ | ↑ | ↑ |`).
* 🔋 **Tesla Model 3 ბატარეისა და ენერგიის კალკულატორი**:
  - Model 3-ის პროფილის არჩევა (Standard Range 60kWh, Long Range 78kWh, Performance 82kWh).
  - მიმდინარე ბატარეის % მითითება და დარჩენილი მარაგის ჩვენება (კმ).
  - მარშრუტზე მოხმარებული ენერგია (მაგ. `~3.9 kWh`) და ჩასვლისას დარჩენილი ბატარეა (`ჩასვლა 75% 🔋`).
* ⛅ **ამინდი რეალურ დროში (Live Weather)**:
  - ტემპერატურა (°C), ამინდის სტატუსი და ქარის სიჩქარე.
* 📺 **YouTube In-Car Music Player (მუსიკა მანქანაში)**:
  - Picture-in-Picture მინი-ფლეიერი რუკის კუთხეში (ჩაკეცვისა და გაფართოების ფუნქციით).
* ⚡ **დამტენები (EV Chargers Layer)**:
  - საქართველოსა და მაგისტრალების სწრაფი დამტენები (Wissol, e-Space, Tegeta, Superchargers) და 1-დაჭერით მარშრუტის დახაზვა.
* ➕ / ➖ **მასშტაბის ღილაკები (Zoom In / Zoom Out)**.
* 🕒 **24-საათიანი საათი (Strict HH:mm Format)**.
* ⛶ **სრული ეკრანი (Fullscreen) & Screen Wake Lock**.

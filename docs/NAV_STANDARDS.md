# ნავიგაციის ეკრანის სტანდარტები (tesla-nav)

ეს არის ჩვენი სამუშაო წესები. ისინი აღებულია საერთაშორისო სტანდარტებიდან და რეკომენდაციებიდან, მორგებულია Tesla-ს ეკრანზე. ყოველი ახალი ვერსია ამ წესებით მოწმდება (2026-11-03-დან, Samvel-ის მოთხოვნით).

## ერთეულები

Model 3-ის ეკრანი: 15″, 1920x1200. ერთი ფიზიკური წერტილი 0.168 მმ-ია. მანქანის ბრაუზერის dpr 1.53-ია, ამიტომ **1 CSS px ≈ 0.26 მმ** (40 px ≈ 10 მმ).

Google-ის რეკომენდაციები `dp`-შია. ის 1/160 ინჩია, ≈ 0.16 მმ, ანუ ≈ 0.62 CSS px. ეს მიახლოებაა: მანქანის ეკრანებზე dp-ის ზომა მწარმოებლის მიხედვით განსხვავდება.

## ყოველი ვერსიის საკონტროლო სია (Claude)

1. `node --check`, `npm test`, `npm run check`, `npm run smoke`.
2. თუ ეკრანი შეიცვალა: 773x601-ზე გაზომვა S1–S6-ით და S11, სქრინშოტით.
3. თუ ნავიგაციის ლოგიკა შეიცვალა: ტესტები გამოგონილ მარშრუტებზე (მოხვევა, გადახვევა, ჩასვლა, გადატვირთვა, Google-ის შეცდომა).
4. თავის შემოწმება: შეცდომისას შეტყობინება თავისით ქრება? ძველი პასუხი ახალს ხომ არ ცვლის? გვერდის გადატვირთვაზე რა ხდება?
